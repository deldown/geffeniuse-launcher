# Security

Report vulnerabilities by e-mail to **support@deldown.de** (not through chat or forums). Please do not publish details before a fix exists.

What happens next:

1. Acknowledgement within 3 working days.
2. Assessment and a fix or workaround; fixes ship through the in-app updater (checksum-verified).
3. If a vulnerability is actively exploited or a severe incident occurred, the legal reporting duties are checked at once (GDPR Art. 33 within 72 hours; Cyber Resilience Act reporting, whether it applies to this free project is still to be confirmed with a lawyer).

Supported: the latest release only.
